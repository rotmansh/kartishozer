# גיבורי ההצלה 🚒🚑🚓🪖

משחק דמיון לגילאי 3–6 בסגנון "טוקה בוקה": בוחרים גיבור ומשחקים איתו בעולם שלו. אין ניקוד ואין "לנצח". רק גוררים, נוגעים ונהנים מהתגובות המצחיקות.

## הדמויות

| דמות | מה עושים |
|------|----------|
| **כבאי** | גוררים את זרנוק המים לחלונות הבוערים ומכבים את האש. גוררים את הסולם לעץ כדי להציל את החתול. לחיצה על הכבאית מפעילה סירנה. |
| **חובשת מד״א** | מטפלים במטופל (ילד, דובי, ארנב או חתול): פלסטר, תחבושת וקרח על הפצעים, מדחום לפה, סטטוסקופ לחזה, תרופה לחום וסוכרייה על מקל. כשהוא בריא הוא אומר תודה ומגיע מטופל חדש. |
| **שוטרת** | לוחצים על השוטרת כדי לשרוק ולעצור את התנועה, והברווזים חוצים את המעבר. מחפשים את הכלבלב שהלך לאיבוד מאחורי השיח, הפח, הקרטון ותיבת הדואר. |
| **חייל** | מלבישים: קסדה, כומתות, משקפי שמש, אפוד ותיק גב (כשהוא לבוש לגמרי הוא מצדיע). מאכילים: פיתה, חומוס, שניצל, תפוח, עוגה, שוקו (עם שפם!), לימון (חמוץ!), פלפל חריף (חריף!) וברוקולי (איכס!). |

## הפעלה

אין צורך בהתקנה. פותחים את `index.html` בדפדפן, גם ישירות מהקובץ. מומלץ טאבלט או טלפון במצב לרוחב.

- כל הצלילים מסונתזים בזמן אמת (Web Audio). אין קובצי שמע.
- אם במכשיר יש קול עברי, הדמויות גם מדברות ("יאמי!", "איכס!", "כל הכבוד!").
- כפתורים: בית (חזרה לבחירת דמות), מסך מלא, השתקה.
- אפשר להיכנס ישר לדמות עם קישור: `index.html#fire`, `#medic`, `#police`, `#soldier`.

## מבנה הקוד

- `js/core.js`: ציור SVG, אנימציות, גרירה, חלקיקים ומעבר בין מסכים
- `js/audio.js`: כל הצלילים, הסירנות והקול
- `js/characters.js`: בניית הדמויות, ההבעות (שמח, עצוב, יאמי, איכס, חמוץ, חריף…) והחיות
- `js/vehicles.js`: כבאית, אמבולנס, ניידת, ג'יפ ומכוניות
- `js/scene-*.js`: מסך לכל דמות
