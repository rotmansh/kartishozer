# קליפי – עורך וידאו חכם (PWA)

אפליקציית ווב לטלפון: בוחרים סרטונים ותמונות מהגלריה, בוחרים שיר וסגנון, וה-AI עורך סרטון שמסונכרן לביט. אחר כך מוסיפים טקסט, סטיקרים ושרבוטים ומייצאים לגלריה.

הכול רץ על המכשיר עצמו. שום קובץ לא עולה לשרת.

## מה ה-AI עושה
- **ניתוח שיר** (`js/beat.js`): מזהה BPM, ביטים ותחילת תיבות (downbeats), ומודד אנרגיה לאורך השיר. בוחר את הקטע הכי חזק בשיר לפי האורך המבוקש.
- **ניתוח מדיה** (`js/analyzer.js`): מדרג כל תמונה וכמה פריימים מכל סרטון לפי חדות, חשיפה, ניגודיות, צבעוניות, תנועה (ורעידות) ופנים (כשהדפדפן תומך). שומר "חתימת צבע" כדי לא לבחור שוטים כמעט זהים.
- **במאי** (`js/director.js`): חותך על הביטים, מהר יותר בחלקים האנרגטיים ולאט יותר ברגועים. בוחר את הרגעים הטובים בגיוון, שומר על סדר כרונולוגי, לא חוזר על אותה תמונה ברצף, ובוחר מעברים לפי הסגנון (פלאש/זום על קפיצות אנרגיה).

## עריכה
- קליפים: סידור, שכפול, החלפה, מחיקה, אורך בביטים, נקודת התחלה, מהירות, זום, התאמה למסך, פילטר לקליפ, סאונד מקורי, "ערבוב AI", יישור לביט.
- 11 מעברים: חיתוך, דהייה, דרך שחור, פלאש, זום, מהיר (whip), החלקה, למעלה, סיבוב, גליץ׳, עיגול.
- טקסט: 6 גופנים בעברית, צבעים, 5 סגנונות (צל, קו מתאר, רקע, ניאון, מדבקה), 7 אנימציות כולל "על הביט".
- סטיקרים: אימוג׳י ומדבקות טקסט מוכנות. גרירה, צביטה להגדלה וסיבוב.
- שרבוט: ציור באצבע עם צבעים, עובי, ניאון ומסגרת, ומופיע עם אנימציית ציור.
- 11 פילטרים (WebGL), פעימת זום על הביט, פסים קולנועיים, כניסה ויציאה בשחור.
- 5 שירים מובנים שנוצרים על המכשיר (בלי זכויות יוצרים), או שיר מהטלפון.
- פורמטים 9:16, 4:5, 1:1, 16:9. ביטול/ביצוע מחדש.
- ייצוא 720p או 1080p, ושמירה לגלריה דרך תפריט השיתוף.

## הרצה מקומית
```bash
cd video-editor
python3 -m http.server 8080
# http://localhost:8080
```
אין שלב build ואין תלויות.

## פריסה
אתר סטטי: אפשר להעלות את התיקייה לכל אחסון HTTPS (Vercel, Netlify, GitHub Pages). ב-Vercel: פרויקט חדש מאותו ריפו, Root Directory = `video-editor`, Framework = Other.
בטלפון: פותחים את הכתובת, ואז "הוסף למסך הבית" כדי שזה ייפתח כמו אפליקציה.

## מגבלות ידועות
- הייצוא קורה בזמן אמת (סרטון של 30 שניות לוקח 30 שניות). צריך להשאיר את המסך דלוק.
- דורש דפדפן מעודכן: Safari ב-iOS 14.5 ומעלה, או Chrome. ב-iPhone הקובץ יוצא MP4. בכרום ישן יותר הוא יוצא WebM.
- הפרויקט לא נשמר אחרי רענון של הדף.
